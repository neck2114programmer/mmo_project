# ⚔️ Эльдория: Клинки Рассвета — 3D MMORPG в браузере

Браузерная средневеково-магическая MMORPG на **Next.js + Three.js + PostgreSQL (Drizzle ORM)**.

* 8 классов (Воин, Ассасин, Маг, Чародей, Щитовод, Лучник, Берсерк, Приручатель), мужской и женский пол
* Редактор внешности (рост, телосложение, лицо, глаза, причёски, цвета, уши, хвосты, метки) с 3D-превью
* 4 локации: Опушка Рассвета (речка, домик, мельница, мост), Пески Ал-Хазар (пирамида, оазис), Лес Друидов (гигантское дерево), Склеп Короля-Лича (данж с боссами)
* 35 квестов, живые NPC (ходят, говорят, торгуют), таргет-система (клик / Tab), автоатака
* Древо навыков: 30 навыков на класс (18 активных, 12 пассивных) — 240 навыков, ранги до 3
* 350+ предметов: 6 уровней сетов брони и оружия для каждого класса, украшения, расходники, бонусы сетов
* Инвентарь, окно персонажа со статами, журнал заданий, карта, миникарта, торговля, чат (Мир / Локация), мультиплеер (другие игроки видны в мире)
* Сохранение прогресса в PostgreSQL

## Установка на ноутбуке (Windows / macOS / Linux)

### 1. Установите
1. **Node.js 20 или новее** — https://nodejs.org (LTS)
2. **PostgreSQL 14+** — https://www.postgresql.org/download/ (запомните пароль пользователя `postgres`)

Либо вместо установки PostgreSQL используйте Docker:
```bash
docker run -d --name eldoria-db -e POSTGRES_PASSWORD=postgres -e POSTGRES_DB=app_db -p 5432:5432 postgres:16
```

### 2. Создайте базу данных (если ставили PostgreSQL вручную)
```bash
psql -U postgres -c "CREATE DATABASE app_db;"
```
(или создайте базу `app_db` через pgAdmin)

### 3. Скачайте проект и установите зависимости
```bash
cd папка-с-проектом
npm install
```

### 4. Настройте подключение
Файл `.env` в корне проекта:
```
DATABASE_URL=postgresql://postgres:ВАШ_ПАРОЛЬ@127.0.0.1:5432/app_db
```
(по умолчанию `postgres:postgres`). Таблицы создаются **автоматически** при первом запуске. При желании можно применить схему вручную: поправьте URL в `drizzle.config.json` и выполните `npx drizzle-kit push`.

### 5. Запуск
Режим разработки:
```bash
npm run dev
```
Продакшен-режим (быстрее, рекомендуется для игры):
```bash
npm run build
npm start
```
Откройте **http://localhost:3000**

### 6. Играем
1. Зарегистрируйтесь на странице входа → вас перекинет на создание персонажа.
2. Выберите класс, пол, настройте внешность, введите имя → «Создать и войти в мир».
3. Вы появитесь на Опушке Рассвета. В следующий раз: вход → выбор героя → «Войти в мир».

Чтобы проверить мультиплеер, откройте игру во второй вкладке/окне браузера (в режиме инкогнито) под другим аккаунтом — вы увидите друг друга и чат.

## Управление
| Клавиша | Действие |
|---|---|
| W A S D / стрелки | движение |
| ПКМ + движение мыши | вращение камеры; колесо — приближение |
| ЛКМ | выбрать цель (моб, NPC, предмет); двойной клик по врагу — автоатака |
| Tab | ближайшая цель |
| 1–0 | навыки и зелья на панели |
| R | автоатака |
| F | говорить / собирать / взаимодействовать |
| Пробел | прыжок |
| I / C / K / L / M | инвентарь / персонаж / навыки / задания / карта |
| Enter | чат (команды: /wave /cheer /dance /sit) |
| H | помощь, Esc — снять цель / закрыть окна |

NPC с жёлтым **!** выдают задания, зелёный **?** — можно сдать. Порталы на краях карты ведут в другие локации (Опушка → Пустыня → Лес → Склеп).

## Если что-то не работает
* **Чёрный экран / ошибка 3D** — включите аппаратное ускорение в браузере (Chrome/Edge/Firefox, WebGL2).
* **Ошибка регистрации** — проверьте, что PostgreSQL запущен и `DATABASE_URL` верный.
* **Низкий FPS** — используйте `npm run build && npm start`, закройте лишние вкладки.

## Структура проекта
* `src/game/data/` — классы, навыки, предметы, квесты, NPC, мобы, зоны
* `src/game/render/` — процедурные 3D-модели: персонажи (`character.ts`), оружие, существа, растения, постройки, мир, эффекты
* `src/game/engine.ts` — игровой движок (управление, бой, ИИ, квесты, сеть)
* `src/components/` — интерфейс (HUD, окна, превью персонажа, сцена входа)
* `src/app/api/` — API: авторизация, персонажи, синхронизация мира и чата
* `scripts/check-data.ts` — проверка целостности игровых данных (`npx tsx scripts/check-data.ts`)
